# PJ Board 操作マニュアル（全体手順書）

PJ Board の全機能の使い方を画面ごとに説明する。目的別の手順は [USECASES.md](USECASES.md) を参照。

---

## 1. ログイン・アカウント

### ログイン
1. ブラウザで PJ Board の URL（例: http://localhost:8100）を開く
2. ユーザーを選択し、パスワードを入力して「ログイン」
   - **初期状態はパスワード未設定**。空欄のままログインできる
3. ログイン状態は30日間保持される（Cookie）

### パスワード・APIトークン（サイドバー左下の 🔑）
- **パスワード変更**: 現在のパスワード（未設定なら空欄）→新しいパスワードを入力。
  変更すると**他の端末のセッションは自動ログアウト**される
- **APIトークン**: 自動化スクリプトやAI（MCP）用の認証キーを発行できる。
  発行直後の1回しか表示されないので必ずコピーして保管。不要になったら「失効」
- パスワードを忘れた場合は、サイト管理者以上に**リセット**を依頼する（組織・ユーザー管理 → 対象ユーザーの「編集」→ 🔑パスワードリセット）
- ログイン失敗が**10分間に5回**を超えると一時ロックされる（10分後に自動解除）

### ログアウト
サイドバー左下の 🚪 ボタン。

## 3. 権限のしくみ（先に読むと迷わない）

実効権限は **組織権限 × プロジェクトロール** で決まる。

| あなたは… | できること |
|---|---|
| マネージャー / プロ職 | 全プロジェクトの管理者（アサイン不要） |
| サイト管理者 | ユーザー・組織の管理とパスワードリセット（PJ内はロールに従う） |
| PJのリーダー | そのPJの全操作（設定・メンバー・スケジュール） |
| PJのメンバー | **自分の担当タスク**の状態・進捗・実績・説明・タグの変更、タスク作成、コメント。日程変更は不可（PJ設定で緩和可） |
| ご意見番（Advisor） | 閲覧＋コメント |
| 未アサインの社内ユーザー | **全PJの閲覧＋コメント**（意見を求められたら答えられる） |
| 外部ユーザー | アサインされたPJのみ。コメント・詳細の閲覧はPJごとに制限されることがある |

操作できない項目はグレーアウト・非表示になる。無理に叩いてもサーバーが拒否する。

## 4. 各ビューの使い方

### 🏠 マイダッシュボード（ホーム）
自分に関係する情報の横断ビュー。関与PJの進捗カード、**全PJタイムライン**、自分の未完了タスク（期限順）、期限超過、横断アクティビティ。プロジェクトカードをクリックするとそのPJのボードへ。

### 📊 ダッシュボード（PJ単位）
- 統計カード / ステータス円グラフ / 担当者別残タスク / 優先度分布 / 週別負荷
- **📉 バーンダウン**: 残タスク数の30日推移
- **⚠ リスクタスク**: 期限3日以内で進捗50%未満、または期限超過のタスクを自動抽出
- **⏱ 工数**: 担当者別の見積h／実績h／差分
- **📄 レポート**: 「週次サマリーを作成」で進捗・完了・リスクの要約をノート（カテゴリ: レポート）に自動生成。Webhook設定があれば同時送信。「📅 iCal」で Outlook 購読用ファイルを取得

### 📋 ボード（カンバン）
- 「ステータス別」と「担当者別」を切替可能
- カードをドラッグ＆ドロップ: ステータス別=状態変更、担当者別=**担当の割り振り**
- 完了列にドロップすると進捗が自動で100%になる
- 権限がないカードはドラッグできない

### 📑 テーブル
- 列ヘッダークリックでソート。セル内で直接編集（ステータス・担当・優先度・日付・見積）
- **一括編集**（管理者のみ）: 左端のチェックボックスで複数選択 → 上部のバーでステータス・担当・優先度をまとめて変更
- 表示される列はPJ設定の「表示設定」に従う

### 📅 WBS / ガント
- 親子タスクからWBS番号を自動採番。▼で折りたたみ
- ツールバー: 日幅ズーム（－/＋/全体表示）、タスク名列の境界ドラッグで幅変更
- **✏ 編集モード**（管理者のみ）:
  - バー中央ドラッグ=日程移動 / **左端=開始日のみ** / 右端=期限のみ変更
  - 左の行を ⠿ でドラッグ=並べ替え、⭢⭠=階層変更、＋=サブタスク追加
  - 最下段の空きレーンを横にドラッグ=その期間で新規タスク作成
  - **📏 基準線保存**: 現在の日程を計画として記録。以後、灰色の細いバーで「計画とのズレ」が見える
- 依存線（先行タスク）・◆マイルストーン・今日線・週末シェード表示

### 📆 カレンダー
期限日ベースの月表示。◆=マイルストーン。←→で月移動。フィルターが効く。クリックで詳細。

### 💬 コメント一覧 → 議論ページ
- 議論のあるタスクのスレッド一覧＋最新コメントの時系列
- スレッドをクリックすると**チャット風の議論ページ**へ。上部にタスク概要、下部に入力欄
- **@メンション**: 「@」を打つと候補が出る（スレッド参加者→PJメンバー→社内の順）。↑↓で選び Enter/Tab で確定。**PJ未参加の人もメンションでき、相手に通知が届く**
- コメントには ✏編集（自分の発言のみ）と ☺+絵文字リアクション（👍✅👀🎉❓）が使える

### 📖 ノート
- PJの共有情報（検証環境・体制・先方窓口・定例・ルール・ツールなど）をカード管理
- 新規PJには**テンプレートの雛形が自動作成**される。「（未記入）」を埋めていく運用
- URL自動リンク・📌ピン留め・カテゴリ・**📎ファイル添付**対応

### タスク詳細（どの画面からでもクリックで開く右パネル）
全項目の編集（権限に応じて無効化）に加えて:
- **🔔ウォッチ**: 変更・コメントを通知で受け取る
- **📎添付ファイル**（20MBまで・主要形式のみ）
- **🔗タスク間リンク**（↔関連 / ⛔ブロック）
- **繰り返し**（毎週/隔週/毎月）: 完了にすると次回分が自動作成される
- サブタスク・先行タスク・タグ・関連リンク・コメント・変更履歴
- 誰かが先に更新していた場合は「他のユーザーが先に更新しています」と表示され自動で再読込される

## 5. 通知

- 右上の 🔔 に未読件数バッジ。クリックで一覧、項目クリックで該当タスクへ
- 通知されるもの: **自分への@メンション** / 担当割当 / 自分の担当タスクへのコメント・状態変更 / ウォッチ中タスクの変更 / **期限リマインド**（明日期限・本日期限・超過、1日1回）
- 他ユーザーの更新は数秒以内に画面へ自動反映される（編集中は邪魔しない）
- Teams/Slack にも飛ばしたい場合は PJ設定の「🔔通知」で Webhook URL を設定

---

## 6. 検索

`Ctrl+K` または右上の 🔍。タスク・コメント・ノートを全プロジェクト横断で検索し、クリックで該当画面へ。外部ユーザーは参加PJのみが対象。

## 7. プロジェクト設定（⚙ / リーダー・組織上位者のみ）

| セクション | 内容 |
|---|---|
| 基本情報 | 名前・説明・期間・カラー |
| ボード列 | ステータスの追加・名前・色・「完了扱い」指定 |
| カスタムフィールド | テキスト/数値/日付/選択肢の独自項目（テーブル・詳細に表示） |
| 表示設定 | 見積・実績／優先度／タグ／カスタムFの表示ON/OFF |
| 権限の細部 | メンバーのタスク作成・日程変更・ノート編集、ご意見番/未アサイン者のコメント許可 |
| 👤 担当者の追加選択肢 | アサイン済みメンバー以外に担当者として選べるラベルを定義（例: **顧客**・先方・ベンダーA）。担当者ドロップダウン・担当者別ボードの列・フィルター・各種表示に反映される |
| 外部ユーザー | アサイン時の既定フラグ、エクスポート許可 |
| 🔔 通知 | Teams/Slack Webhook URL＋送信イベント選択 |
| 📦 データ管理 | **CSVインポート**・**PJ複製**（構成のみ/タスク込み）・iCal出力 |
| 🗑 ゴミ箱 | 削除したタスク・ノートの復元（30日で完全削除） |
| ノートテンプレート | 雛形の編集・「未作成分をノートに作成」 |
| 危険な操作 | アーカイブ / 完全削除 |

### メンバーとロール（サイドバー「プロジェクトメンバー ＋」）
ユーザーのアサイン・解除、ロール変更（リーダー/メンバー/ご意見番）、外部ユーザーの
「💬コメント閲覧」「📄詳細閲覧」個別設定はここで行う。

## 8. 組織・ユーザー管理（🏢 / サイト管理者以上のみ）

- 組織の追加・名前・カラー、ユーザーの追加・編集（役割・所属・**社内/外部**・**組織権限**・メール(SSO用)）
- ユーザーの無効化（担当タスクは残る）・パスワードリセット
- 参加プロジェクトとPJロールの一覧、**🔐ログイン履歴**（成否・IP）

## 9. エクスポート（⬇）

| 形式 | 用途 |
|---|---|
| HTMLレポート | 案件終了後のアーカイブ用。議論ログ込み・単一ファイルでどこでも開ける |
| Excel (.xlsx) | サマリー/タスクWBS/コメント/リンクの4シート |
| CSV | Excelで開ける一覧（BOM付き）。**インポートと同じ列構成** |
| JSON | バックアップ・外部ツール連携用の全データ |
| iCal | ダッシュボードから。Outlook等で期限を購読 |

外部ユーザーはPJ設定で許可された場合のみエクスポート可能。

## 10. AI・自動化から使う

- **MCP**: `mcp_server.py` をAIクライアントに登録（README参照）。環境変数 `PJBOARD_ACTOR_ID`（操作ユーザー）、本番では `PJBOARD_TOKEN`（🔑で発行したAPIトークン）
- **REST API**: `/docs` にSwagger UI。`GET /api/ai/help` にAI向けガイド
- **APIトークン**: `Authorization: Bearer pjb_…` ヘッダーで認証。🔑モーダルで発行・失効

## 11. 運用（管理者向け）

- **バックアップ**: 毎日自動で `data/backups/` に7世代保存。復旧はDBファイルを差し替えて再起動
- **死活監視**: `GET /healthz`
- **テスト**: `python -m pytest tests/ -q`（アプリ更新後に実行を推奨）
- **本番移行**: [DEVELOPMENT.md](DEVELOPMENT.md) 第6章のチェックリストを必ず実施（`PJBOARD_DEBUG=0` 等）
