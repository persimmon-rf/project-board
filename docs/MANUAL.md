# PJ Board 操作マニュアル（全体手順書）

PJ Board の全機能の使い方を画面ごとに説明する。目的別の手順は [USECASES.md](USECASES.md) を参照。

---

## 1. ログイン・アカウント

### ログイン
1. ブラウザで PJ Board の URL（例: http://localhost:8100）を開く
2. **メールアドレス**とパスワードを入力して「ログイン」
   - メールアドレスはユーザー登録時に必須（ログインID。大文字小文字は区別しない）
   - 既存ユーザーにはダミーメール `user{ID}@example.com` が自動補完されているので、
     組織・ユーザー管理から実メールに変更する
   - **初期状態はパスワード未設定**。空欄のままログインできる
3. ログイン状態は30日間保持される（Cookie）
- 開発時（`PJBOARD_DEBUG=0` 未設定）はログイン画面に **🔧デバッグ用ログイン（柿田）**
  ボタンが表示され、パスワード不要でログインできる。本番では無効化される

### パスワード・APIトークン（サイドバー左下の 🔑）
- **パスワード変更**: 現在のパスワード（未設定なら空欄）→新しいパスワードを入力。
  変更すると**他の端末のセッションは自動ログアウト**される
- **APIトークン**: 自動化スクリプトやAI（MCP）用の認証キーを発行できる。
  発行直後の1回しか表示されないので必ずコピーして保管。不要になったら「失効」
- パスワードを忘れた場合は、サイト管理者以上に**リセット**を依頼する（組織・ユーザー管理 → 対象ユーザーの「編集」→ 🔑パスワードリセット）
- ログイン失敗が**10分間に5回**を超えると一時ロックされる（10分後に自動解除）

### ユーザー設定（サイドバー左下の ⚙）
自分の画面・自分宛ての通知にのみ効く個人設定。ユーザーごとにサーバー保存され、どの端末でも同じ設定になる。

| 項目 | 内容 |
|---|---|
| テーマ | ライト / ダーク / OSに合わせる（OSのダークモード設定に追従） |
| 表示密度 | 標準 / コンパクト（文字・余白を詰めて一覧性アップ） |
| ログイン後の初期表示 | ホーム / 前回開いていた画面 |
| デスクトップ通知 | ブラウザ通知で自分宛ての新着をポップアップ（ブラウザの許可が必要） |
| **外部チャットへ転送** | 自分宛ての通知を **Slack / Google Chat / Microsoft Teams / Discord** の Incoming Webhook（個人チャネルやDM用）へ転送。送信形式はURLから**自動判定**（手動指定も可。Slack・Google Chat・汎用=`{"text"}`、Discord=`{"content"}`、Teams=Workflows向けAdaptive Card）。通知の種類（メンション・担当割当・コメント・ステータス変更・期限リマインド等）を選べる。「テスト送信」で疎通確認 |

パスワード変更・APIトークンもこのページの「🔑開く」から。

### ログアウト
サイドバー左下の 🚪 ボタン。

## 1.5 🛠 管理画面（マネージャー／サイト管理者のみ）

サイドバーの「🛠 管理画面」から。3つのタブで構成される。

- **📁 プロジェクト管理**: 全プロジェクトのカード一覧。進捗バー＋期間経過マーカー（赤線）・タスク消化・⚠超過・❓QA待ち・🐢進捗遅れ（期間経過が進捗を20pt以上先行）・💤停滞（7日更新なし）のヘルスバッジ、メンバー構成（外部は赤チップ表示＋公開タブ）を横断で確認できる。**メンバーのアサイン（特に外部ユーザー）は原則ここの「👥メンバー」から行う**
- **📊 横断分析**: メンバー負荷一覧（担当中・超過・今週期限・残見積h・関与PJ数・30日完了数）、担当中タスク数グラフ、週次スループット（完了数8週推移）、期限超過ワースト10（クリックで該当タスクへ）、**外部ユーザーのアクセス状況**（アサイン先・公開タブ・閲覧フラグ・最終ログインのセキュリティレビュー）
- **🏢 組織・ユーザー**: 従来の組織・ユーザー管理（ユーザー作成・組織・ログイン履歴・パスワードリセット）

```

│  🏠 マイダッシュボード │ フィルターバー: 検索・担当・優先度・タグ・☆保存フィルタ      │
│  プロジェクト一覧     ├──────────────────────────────┤
│  プロジェクトメンバー  │                                          │
│  🏢 組織・ユーザー管理 │  ビュー本体（ボード / テーブル / ガント / …）        │
│  ─────────    │                                          │
│  ログインユーザー 🔑🚪 │                                          │
│  👁 表示のみ切替(*)   │                                          │
└────────────┴──────────────────────────────┘
(*) マネージャーのみ。右上の 🔧 は開発時専用（本番では非表示）
```

- **ビュータブ**: 📊ダッシュボード / 📋ボード / 📑テーブル / 📅WBS・ガント / 📆カレンダー / 💬コメント一覧 / 📖ノート
- **URLで共有**: どの画面もURL（`#/p/1/board/t/12` 等）を送れば同じ画面が開く
- **戻る/進む対応**: ビュー切替・プロジェクト切替・タスク詳細の開閉は履歴に残り、ブラウザの戻る/進むボタンで行き来できる
- **キーボード**: `n`=タスク追加 / `1`〜`5`=ビュー切替 / `h`=ホーム / `Ctrl+K`=検索 / `Esc`=閉じる / `Ctrl+Enter`=コメント送信

## 3. 権限のしくみ（先に読むと迷わない）

実効権限は **組織権限 × プロジェクトロール** で決まる。

| あなたは… | できること |
|---|---|
| マネージャー / プロ職 | 全プロジェクトの管理者（アサイン不要） |
| サイト管理者 | ユーザー・組織の管理とパスワードリセット（PJ内はロールに従う） |
| PJのリーダー | そのPJの全操作（設定・メンバー・スケジュール） |
| PJのメンバー | **自分の担当タスク**の状態・進捗・実績・説明・タグの変更、タスク作成、コメント。日程変更は不可（PJ設定で緩和可） |
| ご意見番（Advisor） | 閲覧＋コメント |
| 未アサインの社内ユーザー | **全PJの閲覧＋コメント**（意見を求められたら答えられる） |
| 外部ユーザー | アサインされたPJのみ。コメント・詳細の閲覧はPJごとに制限されることがある。**表示されるタブもPJ設定「外部パートナーの公開範囲」で制限され、API側でも遮断される** |

**外部ユーザーのセキュリティ（多層防御）**

- アサインは**マネージャー／サイト管理者のみ・管理画面のプロジェクト管理から**。実行時に**氏名の確認入力**が必須（プロジェクトメンバーのモーダルからはアサイン不可。API直叩きでも確認入力なしでは拒否）
- 公開タブ・エクスポート許可・閲覧既定の変更は**マネージャー／サイト管理者＋プロジェクト名の確認入力**が必須で、変更はアクティビティに記録される
- 未アサインの外部ユーザーは、データ取得・QA・ノート・メトリクス・エクスポート・添付ダウンロードすべてAPIレベルで遮断
- 外部の閲覧フラグ（💬コメント/📄詳細）の緩和もマネージャー／サイト管理者のみ

**メンバーのアサイン方法（Googleカレンダー風）**: 「プロジェクトメンバー ＋」または管理画面の「👥メンバー」→ 入力欄に名前・組織・メールの一部を入力 → 候補から Enter/クリックで選択（チップ追加、複数可）→ ロールを選んで「N名をアサイン」。

操作できない項目はグレーアウト・非表示になる。無理に叩いてもサーバーが拒否する。

## 4. 各ビューの使い方

### 🏠 マイダッシュボード（ホーム）
自分に関係する情報の横断ビュー。関与PJの進捗カード、**全PJタイムライン**、自分の未完了タスク（期限順）、期限超過、横断アクティビティ。プロジェクトカードをクリックするとそのPJのボードへ。

### 📊 ダッシュボード（PJ単位）
- **統計カード（タスク総数・完了・期限超過）はクリックでその条件のテーブル一覧へ**（フィルターバーに赤いチップが出て、✕で解除）
- **⚙編集（レイアウト編集モード）**: NetBox/Zabbix風の**自由配置グリッド**（12分割×40px行）でウィジェットを編集できる（**自分の画面にのみ**保存される）
  - **何を表示するか**: ✕で外す／「＋ウィジェット追加」で15種から追加（空きスペースに自動配置）
  - **どのサイズで**: **カードの縁をドラッグ**してサイズ変更（右端=幅、下端=高さ、右下角=両方。グリッドにスナップ）
  - **どこに表示するか**: 上部バーを掴んでドラッグし、**好きな座標に自由配置**。他のカードは勝手に詰められず、空きスペースもそのまま残る。他のカードと重なる位置に置いた場合だけ元に戻る（赤枠で警告表示）
  - 変更は即保存。「↺初期配置」でいつでも既定に戻せる。「✔完了」で編集終了。狭い画面（900px以下）では自動的に縦積み表示
- 優先度を非表示にしたPJでは優先度カードは自動的に出ない
- 統計カード / ステータス円グラフ / 担当者別残タスク / 優先度分布 / 週別負荷
- **📉 バーンダウン**: 残タスク数の30日推移
- **⚠ リスクタスク**: 期限3日以内で進捗50%未満、または期限超過のタスクを自動抽出
- **⏱ 工数**: 担当者別の見積h／実績h／差分
- **📄 レポート**: 「週次サマリーを作成」で進捗・完了・リスクの要約をノート（カテゴリ: レポート）に自動生成。Webhook設定があれば同時送信。「📅 iCal」で Outlook 購読用ファイルを取得

### 📋 ボード（※サブタスクを持つ親タスクは表示されません。実作業の単位＝子タスクのみを扱います）（カンバン）
- 「ステータス別」と「担当者別」を切替可能
- カードをドラッグ＆ドロップ: ステータス別=状態変更、担当者別=**担当の割り振り**
- 完了列にドロップすると進捗が自動で100%になる
- 権限がないカードはドラッグできない

### 📑 テーブル
- 列ヘッダークリックでソート。セル内で直接編集（ステータス・担当・優先度・日付・見積）
- 担当者セルには割り当てた**表示色**の帯とドットが付く。**期限超過は赤・3日以内は琥珀色**で表示
- **下位タスクを持つ親タスクは担当欄が「—」**（担当は下位タスクで管理）
- **一括編集**（管理者のみ）: 左端のチェックボックスで複数選択 → 上部のバーでステータス・担当・優先度をまとめて変更
- 表示される列はPJ設定の「表示設定」に従う

### 📅 WBS / ガント
- 親子タスクからWBS番号を自動採番。▼で折りたたみ
- ツールバー: 日幅ズーム（－/＋/全体表示）、タスク名列の境界ドラッグで幅変更
- **✏ 編集モード**（管理者のみ）:
  - バー中央ドラッグ=日程移動 / **左端=開始日のみ** / 右端=期限のみ変更
  - 左の行を ⠿ でドラッグ=並べ替え、⭢⭠=階層変更、＋=サブタスク追加
  - 最下段の空きレーンを横にドラッグ=その期間で新規タスク作成
  - **📏 基準線保存**: 現在の日程を計画として記録。以後、灰色の細いバーで「計画とのズレ」が見える
- 依存線（先行タスク）・◆マイルストーン・今日線・週末シェード表示
- チャート領域は画面内に収まり、**ツールバーと横スクロールバーは常に表示**される。編集モードの操作説明はツールバーの「❓操作方法」にマウスを乗せると表示
- **バーの色は担当者の表示色**（未割当=グレー、親タスク=中立色）。担当者色は組織・ユーザー管理で変更できる

### 📆 カレンダー
月表示。タスクは**Googleカレンダーのように開始日〜期限を1本のバーで横断表示**される（色=ステータス、週をまたぐ場合は端が角ばって継続を表す）。バーの本数に応じて週の高さが自動で広がる。◆=マイルストーン。←→で月移動。フィルターが効く。バークリックで詳細。

### ❓ QA（質問管理表）
顧客・関係者とのQ&Aを管理する。SIの「QA表」相当。

- 一覧: No（QA-001形式の自動連番）・分類・件名/質問・質問者・質問日・回答担当・回答期限（**超過は赤⚠**）・ステータス・回答・回答日・**決定事項・備考**（Excel/HTML出力・取込にも対応）
- ステータス: **回答待ち**（赤）/ 保留（琥珀）/ **回答済み**（青）/ クローズ（緑）。**回答を記入すると自動で「回答済み」になり回答日が入る**
- 行クリックで編集。質問者は自由記入（顧客名OK）、回答担当はPJメンバーから選択（割当時に通知）、関連タスクの紐づけ可
- **やり取り履歴**: 1つのQAで再質問・再回答が繰り返される場合は、編集画面下部の履歴に時系列で記録する（投稿者・日時つき、Ctrl+Enterで記録、一覧に💬件数表示、回答担当へ通知）。最終結論は「回答」「決定事項」欄に集約する運用。Excel出力では「やり取り履歴」列に `[MM/DD 名前] 本文` 形式で整形され、**顧客がセルに行を追記して返送すると取込時に差分だけ履歴へ追加**される（同じファイルの再取込は重複しない）
- ツールバー: 状態・キーワード絞り込み、件数サマリー（回答待ちN件）
- **エクスポート（顧客提出用）**: ツールバーの「📗Excel出力」でタイトル・集計付きの整形済みQA管理表（ステータス色バッジ・期限超過赤字・折り返し・ウィンドウ枠固定）、「📄HTML出力」で単一HTML。エクスポートモーダル（⬇）のページ選択からも出力可。全体アーカイブHTML・全体Excel（QAシート）・JSONにも含まれる
- 追加・編集は管理者/メンバー、削除は管理者のみ

### 📌 課題（課題管理表）
プロジェクトの課題（問題・懸案）を「課題 → 方針 → 実行内容」の流れで管理する。タスクとは独立した台帳。

- 項目: No（`ISS-001` 自動連番）・重要度・分類・件名/課題内容・起票者・起票日・担当者（割当時に通知）・対応期限（**超過は赤⚠**）・状態・**方針**・**実行内容**・解決日
- 状態: **未対応**（赤）→ **対応中**（琥珀）→ **解決済み**（緑）→ **クローズ**（グレー）。解決済み/クローズにすると解決日が自動で入る
- **コメント**: 課題ごとに経緯・対応記録を時系列で記録（投稿者・日時つき、担当者へ通知）
- **関連タスク**: 1つの課題に複数タスクを紐づけ可能（Ctrl+クリックで複数選択）。**ボード・テーブルのタスクには、オープン状態（クローズ以外）の関連課題数が 📌N で表示**され、課題をクローズすると数から外れる。タスク詳細パネルにも関連課題が表示され、クリックで課題へジャンプ
- 絞り込み: 状態（オープンのみ等）・担当・キーワード。件数サマリー（オープン・期限超過）
- エクスポート: 「📗Excel出力」（タイトル・集計付きの整形済み課題管理表。状態色・超過赤字・コメント履歴込み）／「📄HTML出力」。全体アーカイブHTML・全体Excel（課題シート）・JSONにも含まれる
- **外部ユーザーには既定で非公開**（社内の管理情報のため。公開する場合はPJ設定の公開タブで明示的に有効化＋確認入力）

### 💬 コメント一覧 → 議論ページ
- 議論のあるタスクのスレッド一覧＋最新コメントの時系列
- スレッドをクリックすると**チャット風の議論ページ**へ。上部にタスク概要、下部に入力欄
- **@メンション**: 「@」を打つと候補が出る（スレッド参加者→PJメンバー→社内の順）。↑↓で選び Enter/Tab で確定。**PJ未参加の人もメンションでき、相手に通知が届く**
- コメントには ✏編集（自分の発言のみ）と ☺+絵文字リアクション（👍✅👀🎉❓）が使える

### 📖 ノート
- PJの共有情報（検証環境・体制・先方窓口・定例・ルール・ツールなど）をカード管理
- 新規PJには**テンプレートの雛形が自動作成**される。「（未記入）」を埋めていく運用
- URL自動リンク・📌ピン留め・カテゴリ・**📎ファイル添付**対応

### タスク詳細（どの画面からでもクリックで開く右パネル）
全項目の編集（権限に応じて無効化）に加えて:
- **🔔ウォッチ**: 変更・コメントを通知で受け取る
- **📎添付ファイル**（20MBまで・主要形式のみ）
- **🔗タスク間リンク**（↔関連 / ⛔ブロック）
- **繰り返し**（毎週/隔週/毎月）: 完了にすると次回分が自動作成される
- サブタスク・先行タスク・タグ・関連リンク・コメント・変更履歴
- **サブタスクを持つタスクの進捗は自動算出**（子タスク進捗の平均。スライダーは無効化され、直接変更できない）
- **ステータスと進捗は連動**する: 進捗を変えると 0%=未着手 / 1〜99%=進行中 / 100%=完了 にステータスが自動で移る（レビュー中など途中のステータスは1〜99%の間は維持される）。逆にステータスを変えると進捗も変わる（未着手=0 / 完了=100 / 進行中に変えたときは0・100からなら50）
- 誰かが先に更新していた場合は「他のユーザーが先に更新しています」と表示され自動で再読込される

## 5. 通知

- 右上の 🔔 に未読件数バッジ。クリックで一覧、項目クリックで該当タスクへ
- 通知されるもの: **自分への@メンション** / 担当割当 / 自分の担当タスクへのコメント・状態変更 / ウォッチ中タスクの変更 / **期限リマインド**（明日期限・本日期限・超過、1日1回）
- 他ユーザーの更新は数秒以内に画面へ自動反映される（編集中は邪魔しない）
- Teams/Slack にも飛ばしたい場合は PJ設定の「🔔通知」で Webhook URL を設定

## 6. 検索

## 9. エクスポート（⬇）

⬇ボタンで**エクスポートモーダル**が開き、「全体」と「ページ単位」を選べる。

**プロジェクト全体（アーカイブ・バックアップ）**

| 形式 | 用途 |
|---|---|
| 📦 アーカイブHTML | **案件終了後の保管用**。カンバン・WBS・議論ログ・**ノート・アクティビティ履歴**込み・単一ファイルでどこでも開ける |
| 📗 Excel (.xlsx) | サマリー/タスクWBS/コメント/リンク/**ノート**の5シート |
| 📄 CSV | Excelで開ける一覧（BOM付き）。**インポートと同じ列構成** |
| 🗂 JSON | バックアップ・外部ツール連携用の全データ（ノート・履歴込み） |
| iCal | ダッシュボードから。Outlook等で期限を購読 |

**ページ（画面）単位 — 顧客提出用**（ページ＝テーブル/WBS/ボード/カレンダー/ダッシュボード × 形式＝HTML/Excel を選択）

| 形式 | 内容 |
|---|---|
| HTML | 選んだ画面を**Web表示と同じ見た目**の単一HTMLで保存（フィルタ適用状態・編集部品は除去）。印刷→PDF保存も可 |
| Excel | 整形済みシートを生成。**WBSは日単位のExcelガントチャート**（月/日/曜日の3段ヘッダー・担当者色バー・進捗の濃淡・週末シェード・今日マーカー・ウィンドウ枠固定）。テーブル=ステータス色バッジ＋進捗データバー、ボード=ステータス列のカード表、カレンダー=月グリッドに横断バー（セル結合） |

※ダッシュボードはHTML出力のみ。外部ユーザーはPJ設定で許可された場合のみエクスポート可能。

**Excelの往復運用（出力 → 顧客が記入 → 取込）**

テーブル・WBSガント・QA管理表は、エクスポートしたExcelを**そのまま取り込んで反映**できる（各ビューの「📥 Excel取込」、管理者のみ）。

| 対象 | 突合キー | 動作 |
|---|---|---|
| テーブル / WBSガント | **ID列**（出力に自動で入る） | 一致行を更新（タスク名・ステータス・担当・優先度・開始/期限・進捗・見積/実績・タグ）。**ID空欄の行は新規作成**（WBS番号から親を推定）。親タスクの進捗/ステータスは自動算出のため取込対象外 |
| QA管理表 | **No列** | 一致行を更新。**回答が記入されていれば自動で「回答済み」＋回答日**。No空欄の行は新規QAとして追加 |

- **空セルは既存値を保持**する（顧客が触っていない列を消さない）
- 進捗とステータスは、ファイル内で**変更された側**を正として他方を自動連動（例: 進捗だけ77%に変えて返送→ステータスも進行中へ）
- 担当者は氏名でマッチ（スペース・全半角は無視）。取込結果は「更新N件／追加N件／スキップN件」で表示され、アクティビティにも記録される

外部ユーザーはPJ設定で許可された場合のみエクスポート可能。
