# PJ Board ユースケース別ガイド

「やりたいこと」から引く手順集。画面の詳しい説明は [MANUAL.md](MANUAL.md) を参照。

---

## UC-1: 新しいプロジェクトを立ち上げる（リーダー向け）

1. サイドバー「プロジェクト ＋」→ 名前・期間・カラーを入れて作成
   - 作成者は自動的に**リーダー**になり、ノートの雛形（環境・体制・定例…）が自動作成される
2. **メンバーを集める**: サイドバー「プロジェクトメンバー ＋」→ ユーザーを「アサイン」し、ロールを設定
   - 実務担当=メンバー ／ 意見だけ欲しい人=ご意見番 ／ 社外=外部（閲覧範囲を💬📄で調整）
   - マネージャー・プロ職はアサイン不要（全PJの管理者）
3. **ノートを埋める**: 📖タブで「（未記入）」の雛形に検証環境・先方窓口・定例ルールを記入
4. **WBSを作る**: 📅タブ →「✏編集」→ 最下段レーンを横にドラッグしてタスクを期間つきで量産。
   ⭢でサブタスク化、⠿で並べ替え。既存のExcelがあるなら UC-6 のCSVインポートが速い
5. 計画が固まったら **📏基準線保存**（あとで計画とのズレが見える）
6. 定例がTeams運用なら ⚙設定 → 🔔通知 に Webhook URL を設定

## UC-2: 毎日のタスク運用（メンバー向け）

1. ログイン直後の 🏠 で「自分のタスク（期限順）」と期限超過を確認
2. タスクをクリック → 詳細パネルで **進捗スライダー**と**ステータス**を更新（自分の担当タスクは自由に変更可。日程は変更不可＝リーダーへ相談）
3. 作業メモ・質問はコメントへ（`Ctrl+Enter` で送信）。関係者に見てほしいときは **@メンション**
4. 気になるタスクは 🔔**ウォッチ**しておくと変更が通知される
5. 未割当のタスクは担当者を自分に設定して拾える（セルフアサイン）
6. エビデンスやスクショは 📎添付へ

## UC-3: 進捗会議を回す（リーダー向け）

1. 会議前: 📊ダッシュボードで **⚠リスクタスク**（期限接近×低進捗・超過）を確認
2. 「**週次サマリーを作成**」→ 進捗・今週完了・来週期限・リスクがノートに自動生成される（Webhook設定があればTeamsにも流れる）→ これを会議のアジェンダにする
3. 📅ガントで **基準線（灰色バー）とのズレ**を見ながら日程を調整（バー左端=開始のみ、右端=期限のみ動かせる）
4. 決定事項はノートの「決定事項ログ」へ追記
5. 月間の見通しは 📆カレンダー、負荷は 📊の「担当者別残タスク」「⏱工数」で確認

## UC-4: プロジェクト外の人に意見を求める

**社内の全ユーザーは、参加していないPJでも閲覧とコメントができる**（PJ設定でOFF可）。

1. 💬コメント一覧 → 対象スレッドを開く（または詳細パネルの「議論ページで開く」）
2. コメント欄で「@」→ 候補に**（PJ未参加）の人も表示**される → 選んで質問を書き送信
3. 相手には 🔔通知が届く。相手は通知クリック→そのまま議論ページで回答できる
4. 回答者を今後も巻き込むなら「ご意見番」ロールでアサインしておく

## UC-5: 外部パートナーと連携する

1. 🏢組織・ユーザー管理（サイト管理者以上）→ パートナーの組織を作成 → ユーザー追加時に**種別=外部**
2. PJの「プロジェクトメンバー ＋」でアサイン → ロールは自動的に **外部** 固定
3. 見せる範囲を調整: 💬コメント閲覧 / 📄タスク詳細閲覧 のチェックをON/OFF
   - OFFでも WBS・ガント・進捗・担当は見える（進捗共有はできる）
4. エクスポートを許可する場合のみ ⚙設定 → 外部ユーザー → 「エクスポートを許可」
5. 確認したいときは（マネージャーなら）左下 👁「表示のみ切替」で外部ユーザー視点を実際に見る
- 外部ユーザーのログイン画面には**参加PJしか表示されない**

## UC-6: 既存のExcel WBSから移行する

1. Excelを次の列構成のCSVで保存: `WBS, タスク名, ステータス, 担当者, 優先度, 開始日, 期限, 進捗%, 見積h, 説明`（不要な列は省略可。最低「タスク名」があればよい）
   - WBS列（1 / 1.1 / 1.2.1 …）があると**親子関係が自動復元**される
   - 担当者は PJ Board のユーザー名と一致すれば自動で紐づく。日付は YYYY-MM-DD
2. ⚙設定 → 📦データ管理 → 「📥CSVインポート」でファイル選択 → 件数を確認して実行
3. 取り込み後、📅ガントで並び・階層を微調整
- 逆方向は ⬇エクスポート→CSV（同じ列構成なので、修正して再インポートも可能）

## UC-7: 定型プロジェクトを量産する（テンプレート運用）

1. 雛形にしたいPJを整備（ボード列・カスタムフィールド・ノート・標準タスク一式）
2. ⚙設定 → 📦データ管理 → 「📤このPJを複製」
   - **構成のみ**: 列・メンバー・ロール・ノート・設定を引き継ぎ（タスクなし）
   - **タスク込み**: 上記＋タスク（親子・依存も張り替え、進捗は0にリセット）
3. 複製後に期間・メンバーを調整して開始
- 毎週・毎月発生する単発作業は、タスク詳細の「繰り返し」設定（完了にすると次回分が自動作成）のほうが向いている

## UC-8: 案件終了時のアーカイブ

1. 全タスクを完了に整理し、最終の「週次サマリー」を作成
2. ⬇エクスポート → **HTMLレポート**（議論ログ込み・単一ファイル）と **JSON**（完全バックアップ）を保存
3. 必要なら Excel も出力して報告書に添付
4. ⚙設定 → 危険な操作 → **📦アーカイブ**（削除ではなく、横断ビューから外れるだけ。後から解除可能）

## UC-9: Teams / Slack に通知を流す

1. Teams: チャネル → コネクタ → Incoming Webhook を追加してURLをコピー（Slack は App の Incoming Webhooks）
2. ⚙設定 → 🔔通知 → URLを貼り付け、流すイベントを選択（推奨: メンション・担当割当・期限リマインド）
3. 保存 → 以後、該当イベントがチャネルに投稿される（期限リマインドは1日1回）

## UC-10: AI（Claude等）から操作する

1. 🔑（サイドバー左下）→ APIトークンを発行してコピー
2. AIクライアント（Claude Code等）に MCP を登録:
```json
{ "mcpServers": { "pjboard": {
    "command": "python",
    "args": ["<配置先>/mcp_server.py"],
    "env": { "PJBOARD_URL": "http://<サーバー>:8100",
             "PJBOARD_ACTOR_ID": "<自分のユーザーID>",
             "PJBOARD_TOKEN": "<発行したトークン>" } } } }
```
3. 「PJ Boardのプロジェクト1の状況をまとめて」「〜のタスクを作って」等が可能になる
   （list_projects / get_project / create_task / update_task / add_comment / get_notes …）
- スクリプトから直接叩く場合は `Authorization: Bearer <トークン>` で `/docs` のAPIを利用

## UC-11: トラブルシューティング

| 症状 | 対処 |
|---|---|
| タスクを間違って削除した | ⚙設定 → 🗑ゴミ箱 から復元（リーダーに依頼。30日以内） |
| パスワードを忘れた | サイト管理者以上に依頼 → 組織・ユーザー管理 → 対象ユーザー編集 → 🔑リセット |
| ログインがロックされた | 10分待つと自動解除（失敗5回/10分でロック） |
| 「他のユーザーが先に更新しています」 | 画面が自動で最新化されるので、内容を確認して再入力 |
| 編集ボタンが出ない・グレーアウト | 権限不足。自分のロールは詳細パネル右上のチップで確認し、リーダーに相談 |
| 外部メンバーからコメントが見えないと言われた | そのPJのメンバー管理で 💬コメント閲覧 がOFFになっている（仕様）。必要ならONに |
| 通知が来ない | 対象は「メンションされた／担当／ウォッチ中」のみ。気になるタスクはウォッチする |
| データを戻したい | サーバーの `data/backups/`（7世代・日次）からDBを差し替え |
